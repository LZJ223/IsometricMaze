# 2026-11-08｜屏幕空间描边与静态手绘抖动

本次为正式游戏入口增加几何体专用的屏幕空间描边和手绘变形。保留 Godot 4.7.2、GL Compatibility，以及原有固定观察比例、旋转中心、二维编辑和重建流程。

## 文件与接入

| 文件 | 职责 |
| --- | --- |
| `shader/outline.gdshader` | 轮廓、法线折角和深度断层检测，亚像素采样抗锯齿，透明底填色与墨线合成 |
| `shader/jitter.gdshader` | 对已经合成的填色、墨线和覆盖范围执行相同的连续逆向变形 |
| `shader/geometry_data.gdshader` | 辅助几何信息：六轴法线标签、16 位线性深度、覆盖范围，以及兼容渲染器颜色往返补偿 |
| `script/rendering/hand_drawn_renderer.gd` | 共享实体 Mesh、离屏视图、相机同步、风格参数和几何图像的透明输出层 |
| `scene/game.tscn` | `GeometryView` 下新增 `HandDrawnRenderer`，移除旧 `Outline` 节点和其材质 |
| `script/system.gd` | 初始化渲染组件，模式切换时显示/停用几何通道，在最终相机姿态计算完成后同步渲染状态 |
| `test/validation/rendering_validation.gd` | 真实 GL 渲染专项回归及截图输出 |

Game 的三个直接子节点、`GeometryView/Solid` 和 `GeometryView/Camera3D` 保留。主相机继续作为投影、输入和二维对应关系的依据。原 Solid 保留 Mesh 数据但不直接向主视口绘制；两个离屏几何节点使用同一份 ArrayMesh，不生成描边线 Mesh。

## 渲染流程

1. 颜色视图使用现有实体材质、环境与跟随相机的光源，开启四倍 3D MSAA，输出透明背景。
2. 几何数据视图使用独立世界与无光照数据材质，输出法线标签、打包深度和不透明覆盖。关闭数据通道 MSAA，采样使用 nearest，避免不同面的编码混合。
3. outline 阶段读取颜色和几何数据。覆盖变化产生外轮廓，法线标签变化产生折角；同法线处使用平面残差识别遮挡断层。
4. jitter 阶段对整个透明合成图进行一次共享逆向采样，填色、边界和透明覆盖同步变化。
5. 输出到独立 CanvasLayer 1，UIGame 仍在 CanvasLayer 10。进入编辑模式时隐藏输出并停用三组离屏渲染。

所有离屏纹理与游戏逻辑视口等大，维持既有相机与二维投影关系，同时以整幅透明留白容纳对象边界外的描边和抖动。无需使用 CanvasGroup 的隐式 backbuffer；CanvasGroup 本身也不能直接包围 Node3D。

## 几何数据与深度边缘

GL Compatibility 没有内置法线纹理，因此增加数据通道，而不修改实体网格生成接口。数据在 RGBA8 中按 R=六轴面标签、G/B=16 位线性视空间深度、A=覆盖保存。

实际渲染验证发现：即使使用线性 tonemap，Godot GLES3 的 ALBEDO sRGB 近似转换与输出转换仍不是字节精确的往返，会破坏深度高字节。数据着色器明确补偿该转换，六个轴向表面经实际 framebuffer 读取的深度误差均小于 0.000721 世界单位（far=100）。补偿针对当前 GL Compatibility 管线；切换渲染器或升级引擎时应重新运行数据往返验证。

几何纹理为 nearest 采样，平面预测采用实际采样的整数 texel 间距。深度检测使用无除法平面残差，阈值表示世界空间法向距离，避免在掠射角放大正常平面斜率。这也抑制共面体素接缝及面内三角剖分线。

GLES3 颜色转换参考：[Godot scene.glsl](https://github.com/godotengine/godot/blob/master/drivers/gles3/shaders/scene.glsl)、[tonemap_inc.glsl](https://github.com/godotengine/godot/blob/master/drivers/gles3/shaders/tonemap_inc.glsl)。

## 风格参数

在主场景的 `GeometryView/HandDrawnRenderer` 节点上调整：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `line_width` | 2.0 | 逻辑视口像素线宽，0 关闭描边 |
| `ink_color` | `#203047` | 墨线颜色与不透明度 |
| `depth_threshold` | 0.035 | 同法线表面的世界空间平面残差阈值 |
| `jitter_amplitude` | 0.85 | 抖动幅度，限制在 0～3 逻辑像素 |
| `jitter_wavelength` | 48 | 噪声波长；有效值至少为 24 像素及振幅的 16 倍，抑制局部过度拉伸 |
| `style_seed` | 17 | 独立于随机几何体种子的固定笔触种子 |

随机场不含 TIME、帧号或可变随机状态。相机方向连续影响采样坐标，不对逐帧浮点角度重新哈希。相机静止时图像静止，回到相同姿态时恢复相同图像。噪声以关卡世界原点在屏幕的位置为参照，窗口变化不重新抽取种子。

本版采用“先描边合成、再整体轻微扭曲”。这种方式确保线与填色共用覆盖范围，但局部变形仍会给笔宽带来少量拉伸；振幅和波长约束控制其程度。当前未实现扭曲后重建精确屏幕距离场。笔宽和振幅以逻辑视口像素计，窗口整体缩放时会跟随内容比例缩放。

二维轴测图保留原有精确绘制与拾取，本次不为二维网格引入抖动。因此三维手绘外观与二维精确轮廓之间会有亚像素到数像素的风格差异，逻辑投影仍一致。
